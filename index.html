Public / Sovereign Boundary

PLERA is a public edge, not the STOS authority plane.

This repository may publish public-facing pages, sanitized status, continuity guidance, and documentation intended for everyone.

It must not contain or expose:

  • Admin passcodes, Root Secrets, control-plane secrets, or session cookies
  • Private repository payloads or private STOS filesystem material
  • Terminal tickets, local Unix-socket authority, or runtime control credentials
  • Raw private security evidence or unsanitized host diagnostics

STOS remains authoritative behind its sovereign trust and supervision layers. PLERA is the public doorway only.
